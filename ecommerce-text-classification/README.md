# Ecommerce Text Classification

This is the classification based E-commerce text dataset for 4 categories - "Electronics", "Household", "Books" and "Clothing & Accessories", which almost cover 80% of any E-commerce website.

The dataset is in ".csv" format with two columns - the first column is the class name and the second one is the datapoint of that class. The data point is the product and description from the e-commerce website.

## Background and Context:

Product categorization, a key field in natural language processing (NLP), is crucial for e-commerce companies. It involves organizing products into appropriate categories, a task complicated by the vast number of products and their potential for multiple categorizations. Accurate categorization enhances conversion rates, strengthens search engines, and improves Google rankings. A well-structured product taxonomy ensures easy navigation, leading to higher conversion rates. It also enables faster and more accurate search results, creating relevant landing pages that boost search engine indexing and rankings. Automated tools from companies like Amazon assist merchants by categorizing products based on titles or descriptions.
